# 项目设计优化方案

## 1. 优化目标

把《校园大冒险》进一步收束为下面这个体验表达：

`用星露谷的日常循环，承载“我的暑假”式的生活情绪，再用轻奇幻主线做章节高潮。`

这里最重要的不是再加系统，而是明确主次：

1. `先让玩家住进校园与小镇`
2. `再让玩家和人建立关系`
3. `然后用成长与主线把日常抬升成冒险`

## 2. 建议保留的四大设计支柱

### 2.1 生活感优先

玩家最先记住的应该是：

- 每天不同的天气和时段
- 校园、小镇、家三点一线的熟悉感
- 某个同学、老师、摊主每天都在
- 放学后“今天还能做点什么”

也就是说，前台第一关键词应该是 `生活`，而不是 `系统`。

### 2.2 关系比数值更重要

星露谷和《我的暑假》最抓人的部分都不是数值爬升，而是“我认识了谁、和谁更熟了、这个地点对我有回忆了”。  
因此建议把：

- 好感事件
- 邀约同行
- 生日
- 小镇居民日程

放到比战力成长更显眼的位置。

### 2.3 成长要服务于体验，而不是盖过体验

当前 `知识树 / 五维 / 成就 / 图鉴 / 学院分 / 武学 / 魔法` 都成立，但展示上要更克制。  
建议遵循一条原则：

`后台可以复杂，前台要朴素。`

也就是内部继续保留系统联动，但玩家表面看到的主要收获尽量聚焦到：

- 今天认识了谁
- 今天学到了什么
- 今天收集到了什么
- 今天推进了哪件重要的事

### 2.4 奇幻内容作为抬升，而不是常态

奇幻内容非常适合做章节高潮，但不适合一直与日常并行抢焦点。  
建议继续保留三章结构，但在表现上做到：

- 第一章主要是校园生活中逐渐渗出奇异感
- 第二章才明显进入“异世界校园”
- 第三章把奇幻用于情感回收和毕业主题

这样会更贴合“我的暑假”那种先日常、后神秘、再回味的节奏。

## 3. 推荐的体验节奏

### 3.1 前 30 分钟体验

前 30 分钟建议只让玩家稳定体验 5 件事：

1. 在家、小镇、校园之间走动
2. 认识 3 到 5 个关键 NPC
3. 完成 1 个轻任务
4. 体验 1 个小游戏
5. 在夜晚完成一次复习/写日记/睡觉

其它系统不要删，但尽量不要在前 30 分钟同时高频提醒。

### 3.2 日循环节奏

建议把一天的体感明确成下面这个结构：

1. `清晨`：家与出门准备，给当天定情绪
2. `白天`：课程、探索、NPC、轻任务
3. `放学后`：小游戏、社交、收集、支线
4. `夜晚`：阅读、日记、复盘、睡觉

这套节奏非常适合你当前已有的 `cal.js + books.js + mistake.js + game.js` 结构。

### 3.3 周循环节奏

建议把“周”做成玩家稳定期待的节拍器：

- 周一：体能课/一周新安排
- 周三：社团/中段小事件
- 周五：周测/体育节/特殊活动
- 周末：野餐、逛小镇、长支线、隐藏事件

这样玩家会自然形成“这一周我想熬到哪一天”的期待感。

## 4. 建议做的设计收束

### 4.1 系统分层

建议把现有系统分成三层来经营：

#### P0：生活核心层

这是最该优先抛光的层：

- 时间 / 天气 / 季节
- 家 / 小镇 / 校园往返
- NPC 日程与闲话
- 小游戏与收集
- 阅读 / 摘抄 / 日记

#### P1：成长反馈层

这是支撑长期游玩的层：

- 课程
- 错题本
- 知识树
- 委托板
- 社团
- 成长五维

#### P2：章节高潮层

这是负责“惊喜”和“记忆点”的层：

- 武林秘诀
- 魔法学习
- 月光学院
- 时光回廊
- BOSS 战

重点不是砍掉 P2，而是 `让 P2 更晚、更集中、更像奖励`。

### 4.2 奖励语言收束

建议前台重点保留两类奖励表达：

1. `生活型奖励`：好感、照片、图鉴、日记、地点回忆
2. `成长型奖励`：金币、等级、关键能力解锁

像学院分、隐藏计数、局部成长项这类数据可以保留，但尽量少做并列主提示。

### 4.3 手册信息架构优化

当前手册 9 页并不算错，但建议下一步做“分组表达”，让玩家感知更像 5 类内容：

- `关系`：好友、生日、邀约
- `生活`：任务、日历、地点提示
- `学习`：摘抄、课程、错题、复习
- `收藏`：图鉴、背包、照片、卡牌
- `成长`：成就、等级、五维、大事记

这一步不一定马上改代码，也可以先改文案与视觉层次。

### 4.4 章节主题更聚焦

建议把三章主题明确成下面的表达：

1. `第一章：住进这所学校`
2. `第二章：学校背后还有另一层世界`
3. `第三章：回头看这一年的人与事`

这样玩家对章节的记忆不是“玩法包 A/B/C”，而是有清晰情绪曲线。

## 5. 与当前代码结构的对应关系

为了尽量低成本优化，建议优先从下面几个模块入手：

- [`js/ui.js`](../js/ui.js)
  - 优先做手册分组、提示文案收束、前期信息减量
- [`js/game.js`](../js/game.js)
  - 优先做章节 gating、前期事件排序、核心任务曝光节奏
- [`js/cal.js`](../js/cal.js)
  - 优先强化“一周生活节奏”的存在感
- [`js/growth.js`](../js/growth.js)
  - 保留后台聚合逻辑，减少前期高频暴露
- [`README.md`](../README.md)
  - 保持设计口径与实现同步，避免后续判断偏差

## 6. 建议的下一阶段迭代顺序

### 第一阶段：体验收口

- 重写前 30 分钟引导节奏
- 收束提示文案和任务暴露顺序
- 减少早期并行出现的系统数量

### 第二阶段：生活感强化

- 提升 NPC 日程存在感
- 强化小镇店铺、放学后活动、周末事件
- 让“今天在校园里生活了一天”的感觉更强

### 第三阶段：章节抬升

- 把月光学院和时光回廊包装成更明确的“异质空间”
- 把奇幻内容与现实情感绑定，而不是单纯叠玩法

## 7. 一句话结论

这个项目已经足够“大”，接下来最值钱的工作不是继续横向加法，而是做纵向收束：

`让玩家先爱上这所学校，再爱上这个冒险。`
