## 1. s12 驯兽知识与导师（一期）

### s12.1 蒲老师·克制环讲堂（`js/game.js` S.teacherPu）

- 主菜单在「听一课」后**追加**一项 `克制环讲堂（一节）`（保持 0–2 项序号不变，
  旧 smoke 与玩家肌肉记忆不受影响）。
- 首次听讲：三页 `say` 讲透三系克制（虫→水→兽→虫；×1.5 / ×0.75；举例水系打虫系）。
- 随堂 3 问：取 `TAMING_QUIZ` 中 `chart:true` 的题（≥4 备选，seededShuffle 按 day 取 3），
  经 `ask(..., 'science')` 走学习闭环——**答题喂科学 KP → 点亮科学节点 → 反哺宠物守护**，
  闭环自洽。
- 全对 → `f.tame.chart = true`（**克制直觉**）；已学会再来 → 每日一条 NATURAL_TIPS 复习，
  不重复授业。

### s12.2 阿橘·驯兽讨教（`js/game.js` S.petShop）

- 主菜单在「先逛逛」前**追加** `驯兽讨教` 入口（旧流程按文本定位「先逛逛」，不受影响）。
- 三技巧（复用吴老师 SPELLS「付费+理论题」心智；**答错学费退还**，聚焦知识本身）：

| key | 技巧 | 学费 | 前置 | 效果 |
|---|---|---|---|---|
| `soft` | 轻声细语 | 60 文 | — | 捕捉率 **+10%**（`catchChance` 第 5 参 `tame` 进乘区） |
| `eye` | 察言观色 | 100 文 | soft | 菜单页常显「它最怕 X 系招式」；道具栏选中球时显示**估算捕捉率 %** |
| `aid` | 战后急救 | 160 文 | eye | 战后随行伙伴恢复 **30% 满血**（向上取整，封顶满血） |

- 理论题：`TAMING_QUIZ`（≥10 题游戏自洽知识：克制环/球档/口粮/疲惫/异色/体力公式），
  `seededShuffle(TAMING_QUIZ, day*13 + 技巧序号)` 取 1 题；答对 `f.tame[key] = true`。
- 学会后再选 → 阿橘夸你一句并复述要领。

### s12.3 `js/battle.js` 挂钩点

- `catchChance(hpRatio, ballTier, weary, fed, tame)`：第 5 参默认 0，乘区
  `(1 + weary*0.5 + min(fed,2)*0.1 + tame)`，封顶 .92 不变（纯函数，向后兼容）。
- 丢球处（update :554）传入 `F.tame?.soft ? 0.1 : 0`。
- render（petMode 分支）：
  - skill 模式：`f.tame.chart` 时每招尾附克制标记
    `↑ 效果绝佳 / ↓ 效果不佳 / － 势均力敌`（按 `famAdv(me.fam, e.fam)` 实时算）；
  - item 模式：`f.tame.eye` 且选中球 → 行尾显示 `捕捉率约 NN%`
    （同场直接调 `catchChance` 估算，Math.random 期望值不参与）；
  - menu 模式：`f.tame.eye` → 窗内固定一行 `（它最怕X系招式）`（X = 克制敌系的系）。
- flags 读取走 `ADV.Game.flags.tame`（`skillList` 读 `f.martial` 已有先例，无循环依赖）。

## 2. s13 知识树反哺 + 学业奖励（二期）

### s13.1 知识树 × 宠物战（`js/battle.js`）

新纯函数 `petBonus(nodes)`（导出供测试），`nodes = { english, chinese, math, science }`
为各科已点亮节点数（start 时用 `ADV.Mistake.unlocked(sub)` 填入，无 Mistake 时全 0）：

| 科目 | 宠物战加成 | 公式 |
|---|---|---|
| 英语 | **先攻** | `me.spd += min(3, english)` |
| 数学 | **会心** | 攻击招会心率 `min(.15, .05 + .02×math)`，会心 ×1.5 |
| 语文 | **鼓劲** | 鼓劲倍率 `1.35 + .03×chinese` |
| 科学 | **守护** | petGuard 减伤系数 `.5 − .03×science`（下限 .35） |

- `start` petMode 分支：算好存 `act.edu`；有任一加成时开局 log
  `📖 课堂知识在支持着${me.name}！（英语+速度 / 数学+会心 / 语文+鼓劲 / 科学+守护）`。
- `petRound`：`myStrike` 消费 crit/cheer，`foeStrike` 的 petGuard 分支消费 guardFac
  （`Math.max(1, Math.round(d * a.edu.guardFac))`，默认 .5 与现状一致）。
- 设计口径：知识树由「反哺玩家武力」升级为「反哺整个战斗体系」；宠物战数值仍由
  pow/spd/hp 三维主导，课堂加成是锦上添花不喧宾夺主。

## 5. smoke 断言草案

### [5.54] s12 驯兽知识（约 14 断言）

1. `TAMING_QUIZ.length >= 10` 且 `chart:true` 题 ≥ 4；key 唯一。
2. `catchChance` 第 5 参：tame=0 与现值完全一致（回归）；tame 单调提升；tame+满乘区仍封顶 .92。
3. 蒲老师讲堂：`f.tame` 空 → choosePick 走菜单第 3 项（听一课之后）→ 3 题 caption 命中 →
   `f.tame.chart === true`；再进菜单确认第 4 项变复习口径。
4. 阿橘讨教·soft：金币 ≥60 → 学成扣 60、`f.tame.soft` 置位；答错路径退学费。
5. 丢球实战：重载 battle.js，`F.tame.soft=true` + `Math.random=()=>0` 前置下
   `catchChance` 实参链生效（直接断言公式值即可，实战复用 [5.53] 骨架）。
6. eye：`act` 存在时 render 冒烟不抛错；item 选中球时 log/文案含「捕捉率约」（以 render 后
   canvas 桩无异常 + 纯公式复算为准）。
7. aid：Battle 桩返回 `{outcome:'fled', myHp: 8}`、fullHp=20 → S.wildBattle 后
   `f.wildHp === Math.min(20, 8+6) === 14`。

### [5.55] s13 知识反哺（约 10 断言）

1. `petBonus` 纯函数：全 0 → `critCh .05 / cheerMul 1.35 / guardFac .5 / spdAdd 0`；
   {english:5} → spdAdd 3 封顶；{math:10} → critCh .15 封顶；{chinese:5} → 1.5；
   {science:5} → .35 下限。
2. 实战（重载 battle.js + buddy 桩）：`A.Mistake` 设 KP 使 english/science 节点 →
   `act.me.spd` 增加、开局 log 含「课堂知识」。
3. 会心：`Math.random` 桩压线 → myStrike 伤害 = petDamage×1.5。
4. `S._petGift('week'|'month')` → goodBall/petFood 到账；`_petGift('midterm')` →
   未收录 rar≤2 入册且 `s===1`；全收录时折现 +100。
5. 成就墙三项可渲染且条件随 flags 翻转。
