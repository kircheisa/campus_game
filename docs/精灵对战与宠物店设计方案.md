# 精灵对战强化 × 宠物精灵店 设计方案（GBA 宝可梦对标）

> 立项于 2026-09-19，基于 smoke 928/0 全绿基线。
> 对应用户需求三条：
> 0. 小镇开一家宠物精灵店——买卖宠物精灵、宠物球等；
> 1. 武术和攻击打仗太弱——强化对抗攻击系统：攻击术（武术招式 / 魔法招式）、防御（武术防御 / 魔法防御）、逃跑；
> 2. 搜集宠物小精灵（GBA）游戏特点，模仿其核心玩法。
>
> **本轮交付：本文档。实施按第五节分期推进，每期 smoke 全绿后再进下一期。**

## 二、GBA 宝可梦核心机制拆解与取舍

以第三世代（红宝石/蓝宝石/火红叶绿）为准，逐项对标决定「采纳 / 简化 / 不做」。

| # | GBA 机制 | 原作做法 | 本项目适配 | 取舍 |
|---|---|---|---|---|
| 1 | 属性相克 | 17-18 系相克表，克制 ×2、抵抗 ×0.5、本系加成 STAB ×1.5 | 宠物战沿用虫/水/兽循环 ×1.5；玩家战改为**武/魔攻防博弈**（见 3.2） | ✅ 简化 |
| 2 | 物理/特殊分工 | 攻击/特攻两轴，防御/特防两轴 | 武术招式吃 def，魔法招式吃 mdef（= def×0.5，法穿感） | ✅ 简化 |
| 3 | 回合制骨架 | 速度定先手；命中判定；会心 1/16 ×2 | 保留会心 ×1.8；速度决定先手（宠物战引入；玩家战保持玩家先手，boss 二连保留） | ✅ 简化 |
| 4 | PP 制 | 每招 PP 次数，战斗内用尽即不能再用 | **统一 PP 替换冷却 cd**（原味且实现更简单）；变化技也占 PP | ✅ 采纳 |
| 5 | 状态异常 | 中毒/麻痹/灼伤/睡眠/冰冻 + 能力升降 ±6 级 | 不做异常状态（校园日常向，界面负担重）；保留能力升降（攻击↑/会心↑） | ⛔ 简化不做 |
| 6 | 捕捉公式 | a=(3M-2H)×ball×status÷3M，血越少越易捕，球晃 3 次 | **移植核心思想：HP 比例直接进公式**，战斗中随时可丢球，不必先打赢；weary/诱饵作附加乘数 | ✅ 采纳 |
| 7 | 精灵球家族 | 精灵球 ×1 / 超级球 ×1.5 / 高级球 ×2 / 大师球必中 | 已有三档球（+0/+15%/+30%），改为乘数 +0.25/+0.6/+1.2 进入新公式；不做大师球 | ✅ 已有，调参 |
| 8 | 逃跑公式 | F=(我速×128÷敌速+30×次数) mod 256；训练师战不可逃 | P=min(.95, .35+(我速-敌速)×.05+.15×次数)；**训练师战/BOSS 禁逃** | ✅ 采纳 |
| 9 | 伤药道具 | 伤药+20/好伤药+50/全满，战斗内使用 | 现有战斗道具（面包/果汁）+ 新增「精灵口粮」（喂伙伴回满）；不改药水体系 | ✅ 简化 |
| 10 | 队伍 6 只 + 电脑 | 携带 6 只、箱子寄存、首位出战 | **不扩队伍**（buddy 1 只 + 店铺寄售即可，避免背包/切换 UI 大改）；「珍稀精灵架」承担「获取特定精灵」职能 | ⛔ 不做 |
| 11 | 训练师对战 | 不可捕捉、不可逃跑、给钱给经验 | 对战馆训练家阶梯、乌云帮剧情战保持禁捕禁逃；报酬已有 | ✅ 已有 |
| 12 | 进化 | 等级/道具/亲密度触发 | 已有饲养进化（毛毛虫→蝴蝶、蝌蚪→青蛙），不改 | ✅ 已有 |
| 13 | 图鉴 | 捕获登记、进度解锁 | 已有 42 种图鉴 + need 解锁，不改 | ✅ 已有 |
| 14 | 道馆徽章 | 8 徽章解锁技能机/等级 | 已有四科徽章，不改 | ✅ 已有 |
| 15 | 买卖精灵 | **原作没有**（只有交换/放生） | 用户明确要 → 店里开「收购台」（卖）+「珍稀精灵架」（买），定价见 3.1 | ➕ 自创 |

## 三、系统设计

### 3.1 宠物精灵店「精灵小筑」（s9）

**选址**：town 商店街北侧现有三家立面（礼品店 4,8 / 书店 14,8 / 小吃摊 24,8），东端接第四家：

```
building(m, 33, 8, 8, 5, { roof: 'roofG', name: '精灵小筑', to: ['petShopIn', 11, 11, 'up'] });
```

店内用现成 `shopRoom` 模板（25×13），柜台后店员 NPC「**阿橘**」（pal 复用 shopgirl，脚本 `S.petShop`），货架摆球堆/笼子装饰（sprites 已有物件可拼）。门口挂「🐾」店牌（照抄礼品店员模式）。

**商品清单**（并入 collect.js `ITEMS`，价格对齐现有经济）：

| 类别 | 商品 | 价格 | 说明 |
|---|---|---|---|
| 球类 | 树叶球 / 藤编好球 / 月光宝球 | 20 / 60 / 150 | 与石头伯同价（一站式补货，不搞差价） |
| 耗材 | **精灵口粮**（新） | 25 | 喂随行伙伴回满体力；战斗内「道具」栏可用；背包上限 9 |
| 耗材 | 诱饵包（bait） | 10 | 捕捉/虫鸣通用 |
| 工具 | 细纱好网 / 金丝宝网 / 双层大笼 / 彩漆幸运笼 | 150 / 500 / 150 / 500 | 实施时先核对这些目前在哪卖，避免两店重复定价冲突 |

**珍稀精灵架（买宠）**：
- 每日刷新 3 个货架位：固定 1 个 rar1、1 个 rar2、第 3 位 30% 概率 rar3（需图鉴 need 达标才上架对应种）；
- 售价：rar1 = 40 文 / rar2 = 120 文 / rar3 = 300 文；
- 买已入册的种 → 提示「图鉴已有它」但仍可买（求异色个体）；购买走 `gainCritter`，5% 异色照常掷骰；
- 刷新存 `f.petShopDay/petShopShelf`，跨天重掷。

**收购台（卖宠）**：
- 列出持有生物（`col().insects` 中图鉴已收录个体），**随行 buddy 不可卖**（防误卖，提示「它正跟着你呢」）；
- 收购价：`[0, 12, 30, 80][rar]` 文，**异色 ×3**；卖掉 = 移除个体（图鉴收录保留），体验对应 GBA「放生」但给钱；
- 单次最多卖 5 只，防一键清仓误操作。

**经济核算**：捕捉 rar2 平均成本 ≈ 1-2 颗树叶球（20-40 文），卖 30 文 → 微利走量；rar3 净利 260 文但稀有。配合每日首胜 12 文节奏，不通胀。

### 3.2 玩家对抗攻击系统强化（s10，battle.js 重构）

**菜单 GBA 四键化**：

```
┌──────────────────────────────┐
│  ▶ 攻击    防御              │   攻击 → 子菜单两栏：
│    道具      逃跑            │     【武术】【咒语】（含变化技）
└──────────────────────────────┘   防御 → 子菜单：武术防御 / 魔法防御
```

- 「鼓励」移除（实施时 grep 剧情对「鼓励」的依赖，有则迁到道具栏台词）；BOSS 回忆攻击（C 键 photoStrike）**原样保留**。

**招式注册表 MOVES（数据驱动，替换 skillList if 链）**：

```js
const MOVES = [
  // cat: 'wu' 武术 / 'mo' 咒语；kind: atk/heal/shield/weaken/boost/crit
  { key: 'strike', name: '体术',   cat: 'wu', kind: 'atk', pow: 10, pp: 99, col: '#e8ecff', base: true },
  { key: 'sweep',  name: '扫帚剑法', cat: 'wu', kind: 'atk', pow: 13, pp: 6,  need: f => f.martial.sweep,  powAdd: f => (f.martial.lvl||0)*4 },
  { key: 'palm',   name: '崩山掌',  cat: 'wu', kind: 'atk', pow: 14, pp: 5,  ... },   // 刘家拳四式同理
  { key: 'leg', ... }, { key: 'peak', ... },
  { key: 'math',   name: '数学光波', cat: 'mo', kind: 'atk', pow: 16, pp: 6, need: f => f.badges.math, powAdd: f => nd('math') },
  { key: 'cn', ... }, { key: 'bolt', ... },
  { key: 'qi', name: '云手气功', cat: 'wu', kind: 'heal', pow: 20, pp: 3, ... },            // 变化技也占 PP
  // ... 挚友技、星之盾、缚影咒等全部入表
];
```

保底体术 pow=10 常驻——**解决「没学技能就没得选」的空窗**。

**伤害公式（对抗感核心）**：

```js
// 武术：吃满 def；咒语：吃 mdef = ceil(def*0.5)
phys = max(1, round(atk * pow / 12 - def))   × rand(.85,1.15) × mods
magic = max(1, round(atk * pow / 12 - mdef)) × rand(.85,1.15) × mods
// mods：会心 ×1.8（1/16）；boost ×1.35；weaken 敌方 ×0.75；战斗系技能 Lv2/Lv4 各 ×1.1；敌方防御姿态见下
```

对比旧公式 `max(2, atk+rnd-def)`：pow 14 的招式在 atk=16/def=5 时，旧期望 ≈13，新期望 ≈14.9 且高 atk 成长更陡——「越练越痛」，配合 PP 限制总量平衡。

**防御指令（武/魔博弈——用户点名的核心）**：

| 我方防御 | 吃武术招 | 吃魔法招 | 附加效果 |
|---|---|---|---|
| 武术防御 | **减伤 70%** | 减伤 20% | 反震：反弹所减伤害的 25% |
| 魔法防御 | 减伤 20% | **减伤 70%** | 吸星：回复所减伤害的 25% 体力 |

- 敌人也获得防御 AI：HP < 40% 或我上回合用了大威力招（pow≥16）时，按我方倾向猜拳（我常用武术招 → 敌选武术防御），猜中概率 60%，制造「读招」博弈；
- 防御姿态只持续当回合（GBA 无此机制，属本项目自创适配，文档如实标注）。

**敌人数据升级**（ENEMIES 全员加 `mag` 字段标魔攻倾向）：
- 大壮 `mag:0`（纯武力，怕魔法）；小影 `mag:1`（速攻型，spd 8→9）；乌云均衡；保安大爷 `mag:1`（扫帚气功）；遗忘之雾只吃回忆+魔法（不变）。
- 全员 HP 上调 20%（对抗变长），金币 drop 相应 +25%。

**逃跑**：
- `P = min(.95, .35 + (我速-敌速)×.05 + .15×尝试次数)`，spd 取 playerStats().spd vs 敌 spd；
- 成功 → `finish(false)` 但 toast「成功溜走了！」，不扣任何东西、不给「虽败犹荣」经验（新结局类型 `fled`，Growth 不加经验但也不算败）；
- 失败 → 敌人免费攻击一轮（GBA 行为）；`opts.noFlee`（训练师/BOSS）→ 菜单逃跑项置灰，选了提示「对手挡住了去路！」。

**PP 制**：
- `act.pps[key] = move.pp`，用尽置灰显示「（PP 耗尽）」；体术 pp:99 等于不限；
- **删除 cd 冷却机制**（实施时同步改 smoke 中 cd 相关联动断言）。

**先手判定**：宠物战引入速度先手；玩家战维持玩家先手（鼓励轻量），敌 spd≥8 的二连击保留。

### 3.3 宠物对战 GBA 化（s11，wildBattle 画布化）

**S.wildBattle 从 say/choose 对话流 → `ADV.Battle.start(cr.id, { petMode: true }, cb)`**，复用 battle.js 全部画面骨架（敌人位放野生 critter、我方位放 buddy critter，立绘用 sprites.js L943 的圆滚滚生物放大绘制 + bob 呼吸）。

**我方数据**：buddy critter，HP = pow×6+20（沿用现公式，跨天回满、战斗间保留、喂口粮回满——三条现有规则全部不动）。

**宠物招式表 PET_MOVES**：
- 通用：冲撞（pow = 8，pp 99）；
- 系别技（pp 4）：虫系「虫鸣乱舞」/ 水系「水花射击」/ 兽系「猛扑」，pow = 10；
- 变化技「鼓劲」（pp 2）：本回合防御+下回合攻击 ×1.35（教玩家的第一招「博弈」）。

**伤害**：`max(1, (我pow×3 + 招pow - 敌pow×2)) × 相克 × rand(.9,1.1)`；相克虫→水→兽→虫 ×1.5，同系 ×1（沿用擂台口径，文案同步）。

**捕捉 GBA 公式（替换现有 +bi*+weary 粗糙加法）**：

```js
const M = cr.hp * 6 + 20, H = max(1, foeHp);          // foeHp 战斗内实时扣减
const ballBonus = [1.25, 1.6, 2.2][ballTier];          // 树叶/藤编/月光
const P = min(.92, (3*M - 2*H) / (3*M) * .6 * ballBonus * (1 + weary*.5 + min(fed,2)*.1));
```

- 战斗中随时可丢球（道具栏放球），**血磨得越白越好抓**——GBA 核心循环成立；
- 已入册放归 +3 文、新收服邀随行、异色 roll —— 三段现有逻辑原样保留，仅触发环境换成战斗画面；
- 逃跑失败敌人打一轮；无 buddy 时招式栏置灰，只能丢球/喂食/逃跑。

**三系擂台**：本期仅把 `duelRounds` 的结算文案同步新相克数值；画布化列为可选后续（不承诺，避免范围膨胀）。

## 七、风险与对策

1. **battle.js 重构波及 BOSS 战**：photoMode 回忆攻击与「失败 HP=1 不 Game Over」为红线，重构后先跑 BOSS 断言再动数值；
2. **「鼓励」移除的剧情依赖**：实施前 grep `鼓励`，凡文案引用改为通用台词；
3. **经济通胀**：卖宠收益以「每日捕捉量天然受限（窝点惊扰/遭遇频率）」自然封顶，珍稀架限 3 位/日；上线后观察金币曲线（todo.md 既有观察项）；
4. **cd→PP 迁移**：smoke 中既有 cd 断言同步改写，不许为保绿而保留双轨；
5. **菜单一致性**：战斗 UI 与 say/choose/choose 键位（Z 确认 X 取消）完全同构，渗透修复（派发即清 pressed）贯彻到新防御/逃跑分支；
6. **范围控制**：队伍 6 只、电脑箱、异常状态、双打明确不做（第二节 ⛔ 项），防止范围膨胀拖期。
