## 3. 结构口径

- **单一变现出口**：跳蚤市场 `sellable()`（`price > 0` 过滤，game-life.js:1013）是几乎所有
  物品→金币的必经之路；帮助板是少数绕过市场的定向高价收购（鱼 20 > 市场 8×浮动）。
- **技能对曲线的干预**：金鳞传说/渔汛扩竿/理发店造型加成（+1.25× 单日一笔）都是
  提效不破表，未发现复利型循环。

## 4. 本批修复（批次二十九）

1. **鲜鱼参考价 0 → 8**（collect.js）：`sellable()` 过滤 `price>0`，price 0 的鲜鱼
   进不了跳蚤市场——而物品描述明写「可以卖钱」。定价 8 后：帮助板（20）仍占优、
   f7/f10 即时奖金不受扰、钓鱼大赛用独立 FISH_SCORE 不受扰、喂猫/红烧鱼路径不受扰。
2. **拍卖会 caption 补参考价**（game-life.js）：行价 = a×b（9~100）与拍品参考价
   （20~30）完全脱钩，原版不展示参考价——心算全对可能花 95 拍下参考价 20 的球星卡，
   账面「准价拿下」实则巨亏。caption 补「礼品店参考 💰n」后变成真正的
   数学×估值双重判断（出准价拿下行家范，发现行价虚高也可以放弃）。

**调参建议（产出建议，不改数——改不改等实机体感）**：敏感性由**肝度类**（日锁达成率
take）与**封顶类**（连胜 cap）主导，**单价类（鱼价/时薪）垫底**——即使鱼价 +50%，回收
节奏只快 0.65 天。若实机走查体感通胀：先收日锁达成率口径或连胜封顶，动单价基本无效；
反之若觉钱紧，加单价也不如放宽日锁。实机走查记录「一天实际进账」后回填 take 参数即可
让模型贴合真曲线（模型锚点：鲜鱼价 8 / 擂台封顶式 / 温室 300 / 基地末级 250 已被
smoke 源断言钉在游戏源码上，改数必须连模型一起改，不产生静默漂移）。
