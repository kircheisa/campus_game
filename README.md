# 校园大冒险 · Campus Adventure

模仿 **RPG Maker MZ** 风格的 2D 校园冒险游戏，**三章完整剧情 + 番外**。
零素材文件——所有像素美术、67 张地图、16 首音乐全部由代码程序化生成。
含日历天气季节、每日打卡、考试复习、回合制比武、好感送礼、九大收藏图鉴 + 生物图鉴、
十五种课余小游戏（童年怀旧 + **体育运动包**），以及**精灵小筑与画布宠物对战**
（三系克制 / GBA 式捕捉）、**生物课驯兽知识与知识树实战反哺**、
**大模型现场出题**（可选，断网自动回退题库）。
新学期（NG+）有老朋友重逢与专属话题；好感满阶有心里话事件；
周末有集市 / 电影夜 / 钓鱼大赛；后院还能养牛养羊。

## 🎮 怎么玩

**游戏从家开始**：春天的清晨，妈妈送你出门——穿过小镇去阳光中学，
找校长聊聊，开始你的转学生冒险。目标会随进度实时提示（F 手册「任务」页）。

直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（Shift 加速） |
| Z / 回车 / 空格 | 对话 · 调查 · 确认 |
| C | 挥手打招呼 |
| X / Esc | 取消 · 退出小游戏/战斗 |
| **G** | **面向 NPC 送礼**（投其所好！） |
| **F** | **手册**：五组十二页——好友 ｜ 任务·日历 ｜ 图鉴·生物·背包·摘抄 ｜ 课堂·研习 ｜ 成就·成长·技能（↑↓ 切组、←→ 切页） |
| M | 音量三档循环（🔊 全开 → 🎵 仅音效 → 🔇 静音） |
| 🎁 | **神秘密码**：游玩中依次输入 `J I N B I`（「金币」拼音）→ 零花钱 +1000（测试/救急彩蛋） |

## 🔁 日常玩法循环（数十小时的课余生活）

每天醒来都有事做，第二天一切刷新：

- **草丛翻找**（6 处）：随机补全落叶/昆虫图鉴、捡零花钱，次日重置
- **西郊田野挖蚯蚓**：小镇西门外的田野，在松土上翻找蚯蚓（雨后更好挖），
  也能顺手补昆虫图鉴；蚯蚓就是钓鱼的鱼饵
- **河边垂钓**（小镇 2 处 + 田野水渠 2 处）：礼品店买鱼竿，每日三竿，
  拉杆时机小游戏——**挂上蚯蚓，判定范围更大、稀有鱼概率翻倍**；
  钓上来的 8 种鱼进「渔获」图鉴，鲜鱼可以卖钱、喂猫、或请食堂阿姨做成红烧鱼
- **周末河畔野餐**：在场好友好感集体 +1 的温情事件
- **夜捉萤火虫**：夜晚限定的河边星海
- **道场每日陪练**：随机对手，赢零花钱；通关后可挑战隐藏 BOSS
  **保安大爷**（扫地僧！）——击败获得称号与名言
- **模拟考**：期中后每日一练，刷金币与学院分
- **每日一题打卡 streak**、周五周测、随机今日运势
- **NPC 闲话池**：18 位角色每人一套随机台词，每天聊都不重样
- **读书 → 摘抄 → 写日记**：四处都能读书（图书馆书架免费读 / 教室讲台翻课本 /
  书店购买 / 家里书柜重读）；进书后 ↑↓ 选句、←→ 翻页、**Z 键把好句子抄进摘抄本**、
  X 合上书；读完答对「读后思考题」，夜晚在书桌写日记引用摘抄——日记同时算作复习
- **书的守护者们**：图书馆管理员**秦墨**（读书任务 + **借阅台**：借书借期 3 天，
  带对应课本上课知识点 +50%，按时归还奖励零花钱与知识点巩固，超期罚金收书）、
  小镇**旧书翁**（旧书半价 + 收摘抄）、书友会**小卷**（读满 5 本 + 摘抄 15 句可当读书会主讲）
- **老师办公时间**：午休去找老师——今日作业全对奖励翻倍（零花钱 ×2 · 学院分 ×2）；
  正式试炼首错「当面重讲、既往不咎」豁免一次
- **期末成长报告**：毕业仪式上领取——全学期答题/正确率/图鉴/收服/好友/声望/打卡一页聚合，
  按五维之最给老师定制评语；手册「成长」页底部随时可看同款报告条
- **学科奥赛线**：教室 🏆 公告栏每季开一科（春数学·夏科学·秋语文·冬英语）——
  前三日报名，四天备战期里对应科目答对攒「备战度」（攒满 3 次给一次首错豁免），
  第 8 天限时赛 5 题定名次；冠军奖零花钱 + 知识点 + 「奥赛领奖台」拍立得，集满三科冠军解锁「全能学霸」
- **老矿工锻炉**：矿道矿石别急着全卖——找老矿工锻造三件套：**宽口锄**翻一格带翻十字邻格、
  **三嘴壶**浇水顺带浇左右田垄、**硬调竿**搏鱼窗口大一圈；攒够好矿还能上 **II 级**——
  开垄锄一次翻整垄、五嘴壶一次浇整垄、龙骨大物竿鱼窗 128px，矿 → 农 → 钓三线串成一个闭环
- **夜钓限定**：入夜后的河不一样——**月光鱼**只在夜晚咬钩，传说中的**霓虹鲤**更是雨夜才现身
  （+80 文）；各挂成就「夜钓客」「雨夜传说」
- **图鉴交换所**：精灵小筑阿橘新开柜台——重复的小伙伴加一笔换资，就能指定换一只没见过的
  （图鉴收录保留，随时能再接回）；每天还有一单**免费交换请求**，date 定死、稀有度只升不降；
  异色个体和随行伙伴她可不收
- **料理 buff**：自家做的菜不只是礼物——饭桌吃下，当天自带一种加成：
  🧠**好记性**（月光羹/时蔬汤/烤鱼：答对题额外 +1 知识点）、🍖**精力充沛**（蛋包饭/排骨饭/炖菜：
  精力消耗八折）、👟**健步如飞**（曲奇/春卷/南瓜派：走路更快）；过夜失效，背包页能看到食谱全集
- **田野里的人物**：西郊**田伯**（凑 3 条蚯蚓的请求，教你农时农谚）——
  钓到的鱼还能请食堂阿姨做菜、卖给食堂、分给小猫吃

## 🌱 系统开张导览（不轰炸的新手节奏）

玩法不是一上来全摆出来，而是**一天开张一家**：打招呼 → 送礼 → 课余玩法 →
垂钓 → 精灵小筑 → 后院农场 → 道场比武 → 三系擂台，每个系统在条件达成的那天清晨
广播一条「开张」提示（`SYSTEM_TOUR`）。新生阶段的手册任务页只给当下该做的事，
睡前「今日结算单」把一天的收获收束成一句
「🌟 今日收获：图鉴 +N · 知识点 +N」——充实感一眼可见。

## 🥊 道场极限连战（强度墙）

扫地僧认可（或毕业）后，挑战榜开放**极限连战**：六位强者依次上车，
每一关都比前一关更硬（血量/攻击逐级放大），中途没有休息。
最远连胜纪录上墙——3 连胜、5 连胜、巅峰六连各有学院分与成就，
「不败之壁」等你来翻。

- 层与层随地图 / 天气 / 时段 / 季节**平滑淡入淡出**切换；主循环 0.5 秒评估一次，
  声景组合不变时零开销


## 🌤️ 生活系统：时间 · 天气 · 季节

- **一天六时段**（清晨→夜晚）画面色调实时变化；耗时行动推进时段
- **七种天气**：晴/多云/小雨/暴雨/雾/雪/星空——雨有雨丝、雪有飘落、
  春樱瓣、秋落叶；关键剧情固定天气演出（石门=雷雨夜）
- **四季轮转**（每 10 天一季）：校园 BGM 四季变奏、色调与粒子切换
- **每天必须在校务板打卡答题**才能上床睡觉过日；连续打卡有 streak 奖励
- **考试体系**：每日一题 → 周五周测 → 月考 → 期中大考（S 级出限定道具）；
  夜晚在家书桌复习可让考试变简单
